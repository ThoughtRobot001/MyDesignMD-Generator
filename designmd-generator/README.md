# DesignMD Generator

DesignMD Generator is a scaffolded Next.js application for producing DESIGN.md files from Figma links, images, and website URLs.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Anthropic Claude API
- Figma REST API
- Playwright
- Sharp
- Vitest

## Status

This project currently contains typed interfaces, route stubs, parser stubs, generator stubs, component shells, and test scaffolds. Implementation logic is intentionally deferred.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run test
```
